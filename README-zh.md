## 这是什么

影格 Ingbord 是一个在浏览器里跑的分镜 / 镜头表编辑器。

它不要求你会画画。你可以用 3D 人偶摆出机位和走位，一键生成画面底稿，再在上面补两笔箭头和文字；或者直接接入自己的生图 API 出图。最后把所有镜头排好序，导出成制片和摄影能直接用的 Excel 与 PDF。

**它不是画图软件，它是把「这场戏怎么拍」这件事，变成一份能传阅的文档。**

适合的场景：

| 场景 | 你会得到什么 |
|---|---|
| **AI 短剧 / 一人剧组** | 一个人顶五个岗，分镜这一格不再靠口头比划。客户和团队看同一张表。 |
| **广告 / 宣传片提案** | 比稿时递 PDF，而不是一堆散图。镜头号、景别、运镜、时长能对齐。 |
| **短片 / 学生作业 / 毕设** | 拍摄前把每个镜头定下来，现场少返工。 |
| **实拍前的地勘和预演** | 用 3D 摆位确认机位和轴线，避免到了现场才发现穿帮。 |

## 30 秒上手（不用装任何东西）

1. 打开 **https://miatoo.github.io/Ingbord/**（备用地址：https://www.aitocg.cn/ingbord/）
2. 在 **Board** 里新建镜头，上传或替换画面
3. 选中某个镜头 → 切到 **3D Pose** 摆人偶和机位 → 生成画面 → 到 **Annotation** 补箭头和文字
4. 回到 Board 拖动排序 → 导出 Excel / PDF

## 核心功能

| 功能 | 说明 |
|---|---|
| **Board 镜头板** | 管理所有镜头，上传/替换画面，拖拽排序，一眼看完整个序列 |
| **3D Pose 摆位** | 摆 3D 人偶与摄影机，确定机位、景别与轴线，一键生成镜头画面 |
| **Annotation 标注** | 笔刷、直线、矩形、椭圆、箭头、文字、填充；图层与撤销/重做 |
| **AI Image** | 内置生图通道（测试中）+ 自带 API 双模式；用提示词或参考图出画面，支持多版本切换 |
| **导出** | 项目文件（`.clapboard` / JSON）、Excel、CSV、图片 ZIP、PDF |
| **多项目库** | 项目存在浏览器本地，刷新不丢；可同时管理多个项目 |
| **中英双语 + 主题** | 顶栏切换界面语言与主题 |

### 3D Pose 里有什么

- 人偶：成年男女、青少年男女、儿童、婴儿，可换发型、表情、手势
- 道具与场景：桌椅、床、门窗、车辆、树木、灯具等内置模型，也可导入自定义 `.glb`
- 机位：预设摄影机与场景机位，支持轨道拖拽、平移、滚轮缩放
- 操作：选中对象后移动 / 旋转 / 缩放；**生成镜头画面**会直接写入当前镜头

### Annotation 里有什么

- 笔刷引擎支持压力曲线、笔刷预设与 `.abr` 导入，笔刷可导出复用
- 图层管理、撤销重做（`Ctrl+Z` / `Ctrl+Y`）
- `Tab` 键收起/展开浮动面板
- 标注跟着镜头一起保存，导出时一并合成

### AI Image 里有什么

有两种用法：

**1）内置通道（测试中）** —— 官方在线版和桌面安装包内置了一条生图通道，打开就能试，不用先去申请 API Key。

> ⚠️ 这条通道还在测试阶段，可能遇到排队、限流、模型临时调整，也可能随时中断。**正式干活建议切到「自带 API」，别把交付压在测试通道上。**

**2）自带 API（推荐）** —— 填自己的 endpoint、Key、model，费用直接结算给模型厂商，不经我手。支持自动识别三种主流接口格式：

| 接口格式 | 地址特征 |
|---|---|
| OpenAI 风格 | `/v1/images/generations`、`/v1/chat/completions` |
| Gemini | `/v1beta/models/...:generateContent` |
| Nano Banana | `/v1/draw/...` |

其他兼容 OpenAI 的接口一般也能直接用。生成时可以带最多 **3 张角色参考 + 3 张场景参考**，与当前分镜草图合并进同一次请求，不会拆成多个计费任务。出图后可以「保存为新版本」，在同一镜头下对比不同方案。

> 📌 从本仓库源码自行构建的版本只包含「自带 API」这一条路，内置通道属于官方发行版。本地构建时请在 AI Image 面板里填好配置再生成。

## 导出：这才是交付物

分镜做完要能交出去。当前支持：

| 格式 | 用途 |
|---|---|
| **PDF** | 递客户、比稿、打印上墙（页面底部带一行 Ingbord 署名） |
| **Excel** | 给制片排期和预算，字段可直接对齐通告单 |
| **CSV** | 导入其他表格工具或自建统计 |
| **图片 ZIP** | 批量拿单帧画面，丢进 Keynote / PPT |
| **项目文件 `.clapboard` / JSON** | 完整备份，换设备、换浏览器都能恢复 |

也可以**反向导入 Excel**，把已经排好的镜头表带进来继续改。

## 安装方式

### 方式一：在线版（最省事，推荐）

直接开 **https://miatoo.github.io/Ingbord/** 就能用，不需要注册、不需要下载。

### 方式二：装成桌面应用（免安装包）

用 Edge 打开上面的地址 → 右上角菜单 **「应用」→「安装此站点为应用」**；或在 Chrome 里 **「更多工具」→「创建快捷方式」**，勾选「在窗口中打开」。

得到的是一个独立窗口，没有地址栏，开始菜单里有图标，用起来和桌面软件基本一致。**全程不经过安装包。**

### 方式三：桌面安装包 / 安卓

在 [Releases](https://github.com/Miatoo/Ingbord/releases) 下载。当前版本 **v1.0.1-beta（测试版）**：

| 平台 | 文件 | 大小 |
|---|---|---|
| Windows 64 位（推荐） | `Ingbord-Setup-1.0.1-beta-x64.zip` | 90 MB |
| Windows 32 位 | `Ingbord-Setup-1.0.1-beta-ia32.zip` | 85 MB |
| Windows 便携版 64 位 | `Ingbord-Portable-1.0.1-beta-x64.zip` | 90 MB |
| Windows 便携版 32 位 | `Ingbord-Portable-1.0.1-beta-ia32.zip` | 85 MB |
| Android 内测 | `Ingbord-1.0.1-beta-debug.apk` | 25 MB |

> 桌面版的压缩包里是 `.exe`，**下载后先解压**。便携版解压即用，不写注册表。

#### 首次运行的一个小提示

Windows 在第一次运行安装包时可能弹出代码签名证书警报。处理很简单：

1. 点 **更多信息**
2. 点 **仍要运行**

之后就正常了。这是 Windows 对所有没有签名证书的程序的默认行为，和个人开发项目尤其常见，与软件本身安全与否无关。

## 数据存在哪里

**全部存在你自己浏览器的本地存储里，不上传服务器、不需要账号**。页面加载完成后，断网也能继续编辑分镜（AI 生图除外——它需要联网，走内置通道或你配置的 API）。

这意味着两件事：

- 好处：没有云端泄露风险，断网也能改分镜。
- 注意：换电脑、换浏览器、清理浏览器数据，本地项目会看不到。**重要项目请导出 `.clapboard` 项目文件做备份**，这是目前唯一的跨设备迁移方式。

AI 生图如果走自带 API，Key 只保存在本地；走内置通道则不需要你提供 Key。

> 关于 AI 生图的两种模式，见上文 [AI Image 里有什么](#ai-image-里有什么)。

## 常见问题

**需要注册登录吗？**
不需要。打开就能用。

**会画画才能用吗？**
不需要。3D 摆位 + AI 生图 + 标注，三种方式都能出画面。会用鼠标就能上手。

**能商用吗？**
软件本身用 CC BY-NC-SA 4.0 授权，**非商业用途可自由使用、修改、分发**。商业场景使用（例如公司内部商业项目、对外收费服务）请联系作者获取授权。**你用 Ingbord 做出来的分镜作品，版权完全归你，不受此限制。**

**AI 生图一定要自己有 API 吗？**
不一定。在线版和桌面安装包内置了一条生图通道，打开就能试，但**它还在测试阶段**，可能排队、限流或中断。要稳定出图、要批量做，建议填自己的 API Key：支持 OpenAI 风格、Gemini、Nano Banana 等接口，费用直接结算给模型厂商，不经我手。

**内置通道能长期免费用吗？**
测试期间的规则可能随时调整，不承诺额度、速度和稳定性。把它当试用入口，别当生产工具。要长期稳定，请用自己的 API。

**用自己的 API 会不会更贵？**
单价取决于你选的模型厂商，Ingbord 不加价、不抽成。你也可以选更便宜的模型先出草稿，定稿再换好模型重出一版。

**支持哪些语言？**
界面中文 / English，顶栏可切换。

**有 macOS / iOS 版吗？**
还没打包。但**在线版在所有系统的浏览器里都能用**，Mac 上也可以用 Edge 装成独立窗口。

**发现 Bug 或想提需求？**
开个 [Issue](https://github.com/Miatoo/Ingbord/issues)，写清系统、浏览器版本和复现步骤，会看到。

## 本地构建

需要 Node.js 18+（推荐 20 / 22）。

```bash
npm install
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 产物在 dist/
```

`dist/` 是纯静态文件，丢到 Nginx、Cloudflare Pages、Vercel、GitHub Pages 都能跑。部署细节见 [DEPLOY.md](DEPLOY.md)。

> `npm install` 之后出现 `vulnerabilities`、`looking for funding` 这类提示一般是**警告不是失败**。只要能看到 `audited … packages` 且 `npm run dev` 能起来就没问题。**不要运行 `npm audit fix --force`**，它会打乱依赖版本导致构建失败。

技术栈：React 18 + TypeScript + Vite + Zustand + Three.js + Tailwind CSS。
